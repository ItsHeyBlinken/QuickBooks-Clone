# Product Context

## Problem
QuickBooks is forcing desktop users to cloud subscriptions. Existing offline alternatives (Manager.io, GnuCash, AccountEdge) have gaps: limited reporting, no cash-basis flexibility, clunky imports, no modern UX.

## Solution
A modern offline desktop app with:
- True cash/accrual report flexibility on one double-entry ledger
- Intelligent local bank import (rules → fuzzy match → ML)
- Professional reporting with drill-down
- Encrypted accountant export without cloud

## User Journeys

### Freelancer (Phase 1)
1. Create company file → seed chart of accounts
2. Add customer → create invoice → record payment
3. Import bank CSV → review/categorize → approve
4. Run cash-basis P&L and Balance Sheet

### SMB from QBD (Phase 2)
1. Open company → manage AR/AP with bills and payments
2. Reconcile bank account monthly
3. Toggle cash vs accrual on reports
4. Batch invoice multiple customers

### Accountant (Phase 3)
1. Client sends encrypted export package
2. Open in Accountant Viewer (read-only)
3. Review reports and transaction detail

## Competitive Positioning
"Secure, Reliable, and User-Controlled Accounting for Small to Medium Businesses"
