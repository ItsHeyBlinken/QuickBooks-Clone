# Project Brief

## Product Name
LedgerLocal (working title) — Offline Desktop Accounting Software

## Mission
Build a secure, offline-first desktop accounting application that competes with QuickBooks Desktop and Online by giving small businesses complete control over their financial data without subscription lock-in.

## Target Users
- Sole proprietors and freelancers (cash-basis, simple invoicing)
- Small businesses migrating from QuickBooks Desktop (double-entry, AR/AP, reconciliation)

## Core Value Propositions
1. **Own Your Data** — Financial data stays on the user's machine, encrypted locally
2. **No Monthly Fees** — One-time purchase with optional annual maintenance
3. **Speed & Reliability** — Works fully offline, no cloud latency
4. **Intelligent but Local** — Smart categorization learns locally without sending data to servers

## Scope (Phased)
- **Phase 1:** Double-entry MVP — CoA, invoicing, expenses, CSV bank import, cash-basis reports
- **Phase 2:** SMB parity — accrual toggle, full AP, reconciliation, batch invoicing, OFX/QIF, multi-company
- **Phase 3:** Differentiators — drill-down reports, FTS5/ML import, accountant export, inventory, payroll calc
- **Phase 4:** Ship — code signing, offline licensing, updater, tier gates, marketing site

## Pricing Tiers (from strategy docs)
| Tier | Price | Key Features |
|------|-------|--------------|
| Basic | $199 one-time | Core bookkeeping, invoicing, basic reporting |
| Pro | $399 one-time | + inventory, multi-company, advanced reporting, payroll calc |
| Enterprise | $799 one-time | + batch invoicing, multi-user/LAN, advanced customization |

## Out of Scope (v1)
- Cloud sync, tax filing, direct deposit payroll, mobile apps
